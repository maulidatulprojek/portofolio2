# Coffee Sales Analysis ☕📊

Repository ini berisi dataset dan analisis sederhana mengenai **penjualan kopi** berdasarkan waktu, metode pembayaran, dan jenis produk. Data digunakan untuk keperluan **portofolio data analysis**.

---

## 📁 Dataset
File utama:
- **Coffee_sales.xlsx**

Dataset berisi **3.547 baris data transaksi penjualan kopi**.

---

## 📊 Informasi Kolom

| Kolom | Deskripsi |
|------|----------|
| Hour_of_day | Jam terjadinya transaksi |
| Time | Waktu transaksi (jam & menit) |
| Date | Tanggal transaksi |
| Weekday | Hari transaksi (Mon–Sun) |
| Weekdaysort | Urutan hari (numerik) |
| Month_name | Nama bulan |
| Monthsort | Urutan bulan (numerik) |
| Time_of_Day | Kategori waktu (Morning, Afternoon, dll) |
| coffee_name | Nama produk kopi |
| cash_type | Metode pembayaran (cash / card) |
| money | Total nilai transaksi |

---

## 🎯 Tujuan Analisis
Beberapa tujuan dari analisis dataset ini antara lain:
- Mengetahui **produk kopi paling laris**
- Menganalisis **waktu penjualan tertinggi**
- Melihat **pola pembelian berdasarkan hari dan bulan**
- Membandingkan **metode pembayaran (cash vs card)**
